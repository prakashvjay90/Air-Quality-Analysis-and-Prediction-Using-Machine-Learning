# PADV Activity 2 — Air Quality Analysis and Prediction Using Machine Learning

## Project Overview

This project focuses on analyzing air quality data and predicting Nitrogen Dioxide (NO2) concentrations using machine learning. It includes data preprocessing, exploratory data analysis, interactive visualizations, and predictive modeling.

## Live Interactive Dashboard
https://air-quality-analysis-and-prediction-using-machine-learning-qyd.streamlit.app/

## Dataset

**Dataset:** Air Quality UCI Dataset

The dataset contains air pollution measurements and environmental sensor readings used to analyze air quality patterns.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Plotly
- Scikit-learn
- Streamlit
- GitHub

## Machine Learning Model

**Algorithm:** Random Forest Regression

**Evaluation Results:**

| Metric | Value |
|---|---|
| MAE | 21.9477 |
| RMSE | 31.9581 |
| R2 Score | 0.6484 |

## Project Features

- Air quality data cleaning and preprocessing
- Exploratory data analysis
- Interactive pollutant visualizations
- Correlation and feature importance analysis
- NO2 concentration prediction
- Machine learning performance evaluation
- Interactive Streamlit dashboard

## Conclusion

This project demonstrates how machine learning and data visualization can be used to analyze air pollution patterns and estimate NO2 concentrations. The interactive dashboard provides an accessible way to explore air quality measurements and model predictions.
